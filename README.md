# MakkaTravel Admin
Nuxt 4 (SPA) · UnoCSS · Arabic RTL

```bash
cp .env.example .env     # NUXT_PUBLIC_API_BASE=http://localhost:4000/api
pnpm install
pnpm dev                 # http://localhost:3001
pnpm build               # static SPA via `pnpm generate` → .output/public
```
Login with an ADMIN/EDITOR account from the backend seed.
